# 📓 个人笔记系统 (命令行版)

一个基于 Python 的命令行笔记管理工具，支持增删改查、多关键词搜索、标签分类、分页显示和 JSON 持久化。

## ✨ 功能特性

- ✅ 添加笔记（标题、内容、标签）
- ✅ 列出所有笔记（分页显示）
- ✅ 删除笔记
- ✅ 编辑笔记
- ✅ 模糊搜索（多关键词 AND 匹配）
- ✅ 按标签搜索
- ✅ 数据自动保存到 `notes.json`

## 🚀 快速开始

### 环境要求
- Python 3.6+
- 无需安装第三方库（仅使用标准库）

### 下载
```bash
git clone https://github.com/你的用户名/notes-cli.git
cd notes-cli
